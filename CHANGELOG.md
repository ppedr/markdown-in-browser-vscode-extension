# Changelog

## 0.1.0

- First release: **Open in Browser** on any `.md` or `.markdown` file, from the Explorer and editor
  right-click menus, the editor title bar and the Command Palette. The file opens rendered in the default
  browser, served from a local server on `127.0.0.1`.
- Relative links to other Markdown files open rendered in the same tab, and relative images load.
- The page updates in place when the file is saved in VS Code, keeping the scroll position.
